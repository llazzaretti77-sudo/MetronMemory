# MetronMemory

Memoria di lavoro di Claude Code per il progetto **Moretti BDM / Metron** (collezione BdmSviluppo, SAP, listino, pannello sagomato, editor esterno).

- `MEMORY.md` è l'indice: una riga per nota.
- Ogni nota è un file `.md` con un'intestazione (`name`, `description`, `type`: user, feedback, project, reference) e il testo.
- I link `[[nome]]` rimandano ad altre note.

Le note sono istantanee del momento in cui sono state scritte: prima di usarle, controllare che file, procedure e valori citati esistano ancora.

Repository **privato**: contiene dettagli del cliente e di SAP.
